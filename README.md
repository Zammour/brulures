# Brûlures – recueil des mesures

Application web (PWA) de recueil des mesures de l'étude de rinçage après brûlure cornéenne lipophile (yeux porcins ex vivo, CHU de Strasbourg).

- Fonctionne hors ligne, installable sur l'écran d'accueil.
- Synchronisation via un script Google Apps Script (adresse et code d'accès saisis dans l'application, jamais stockés ici).
- Aucune donnée expérimentale n'est stockée dans ce dépôt.
